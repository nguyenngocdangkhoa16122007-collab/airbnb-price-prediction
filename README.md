# Airbnb Price Prediction in New York City

## Project Overview

This project investigates Airbnb listing price prediction in New York City using machine learning models. It compares six regression algorithms and analyzes model-relative pricing deviations across different listing segments.

## Dataset

- **Source:** [New York City Airbnb Open Data (2019)](https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data)
- **File:** `AB_NYC_2019.csv`
- **Observations:** 48,895 listings
- **Features:** 16 columns

The original dataset should be placed in:

`data/raw/AB_NYC_2019.csv`

## Machine Learning Models

The following models are evaluated:

1. Linear Regression
2. Ridge Regression
3. Lasso Regression
4. Random Forest
5. XGBoost
6. Gradient Boosting

```bash
pip install -r requirements.txt
```

## Reproducibility

1. Clone this repository.
2. Install the required dependencies.
3. Place the original dataset in `data/raw/`.
4. Open and run the notebook in `notebooks/`.

- The original dataset is not reproduced in this repository's documentation.
